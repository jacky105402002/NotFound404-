# NotFound404 工作室網站 V2
## 目標與授權
2026-11-06 使用者要求依最新 MingMing 工作流產出網站，並確認 NotFound404、V2、可操作但不傳送資料的預覽表單、非政府標案。
本次授權涵蓋本機網站實作、素材下載、必要開發工具及驗證；不包含對外部署、commit、push、真實表單送出或修改 Figma。先前準備範圍保存在 docs/project-setup-spec.md。
## 範圍
製作繁體中文單頁網站：導覽、Hero、四項服務、三個示範案例、專案需求預覽、頁尾與行動導覽。
採用 Figma V2 桌機 117:414／手機 117:592，使用官方 MCP 最新高保真資料；品牌依使用者改成 NotFound404。
## 驗收條件
- AC-WEB-01：本機可啟動，主要區塊完整，品牌一致，320／390／768／1440 寬度無水平溢出。
- AC-WEB-02：沿用 V2 色彩、排版、桌機雙欄 Hero、四卡服務、三卡案例與手機單欄；素材本機化且無暫時 Figma URL。
- AC-WEB-03：導覽可到達目標、手機底部導覽可操作、案例可開啟詳情並以 Escape 關閉、焦點返回原按鈕。
- AC-WEB-04：稱呼及 Email 必填且驗證，服務可複選，產生可修改的需求摘要；無資料傳送、持久化、分析追蹤或假送出成功。
- AC-WEB-05：示範案例與終端機標示示意；不出現未核實的效能／時效／加密保證及未核實聯絡資料；有鍵盤焦點、語意標籤、reduced-motion。
- AC-WEB-06：完成產品測試、桌機／手機視覺檢查、自我審查、操作說明與可追溯證據，工作流驗證不冒充網站驗證。
