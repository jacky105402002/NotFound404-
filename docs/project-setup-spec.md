# 工作室網站：啟動規格草案

## 目標

以朋友提供的 Figma 為設計來源，為工作室建立可持續開發的網站專案。本輪只準備專案、採用最新 MingMing 工作流與整理設計交接。

## 範圍

允許：在既有「工作室專案」導入固定版工作流、建立啟動文件、核對檔案與工作流狀態。

本輪不進行網站功能實作、套件安裝、對外品牌定案、建立遠端 repository、commit、push、部署、填送真實表單或修改 Figma。

## 準備階段驗收條件

- AC-SETUP-01：沿用既有側邊欄專案，工作流來源為已查證 v1.1.3，保存版本與來源。
- AC-SETUP-02：Figma 來源、已觀察設計及未決事項可供下一次開發接續。
- AC-SETUP-03：狀態明確標示規劃草案，不將模板或上游測試等同網站完成。

## 下一階段

網站屬新功能，預計走 Full-Loop。正式功能 AC、技術棧、節點拆分及 Design／Implementation Ready 需在版本、品牌、表單與政府標案屬性核對後建立。現階段未開始任何實作 Node。

設計資訊見 [Figma 交接](figma-handoff.md)。這是準備階段歷史快照，現行狀態見 tasks/current/state.json。
